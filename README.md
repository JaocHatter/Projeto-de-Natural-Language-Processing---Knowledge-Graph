## Apresentação

Este projeto nasceu na disciplina de Processamento de Línguas Naturais da Unicamp, oferecida no
segundo semestre de 2026. Seu objetivo é extrair entidades e relações clínicas de relatos de caso
(MultiCaRe/PubMed Central) e organizá-las em um grafo de conhecimento.

## Entregas
